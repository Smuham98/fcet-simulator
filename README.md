# FCET Value Simulator

Interactive techno-economic model for FCET's thin-film ceramic electrolytes.

- **Module 1, Stack economics:** savings per kW and per stack, FCET's share, and a comparison with the manufacturer's next-best option.
- **Module 2, Operating temperature:** the value of running stacks at 550–650 °C instead of about 800 °C.
- **Module 3, Revenue goal and TAM:** the conditions needed to reach a revenue or profit goal.

All starting figures are illustrative placeholders, not FCET forecasts.

**Live version:** open `index.html` in a browser, or visit the GitHub Pages link for this repository.
